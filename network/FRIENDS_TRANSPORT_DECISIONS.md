# BRAWL｜オンライン通信の共通化判断記録（2026-10-20）

対象: 友達用4モード（通常・ドラフト × 1vs1・2vs2）。これは **実装コードを見て判断した開発向けの記録**。古い `network/README.md` の V2.8/3010 基準値と、今の候補 31/3012/1031/13012 を混同しないこと。

## 結論：共通化するのは「同じ責務・同じ処理」だけ

| 項目 | 通常1vs1 / ドラフト1vs1 | 通常2vs2 / ドラフト2vs2 | 判断 |
|---|---|---|---|
| ルーム・通信プロトコル | `rooms`、31 / 1031 | `rooms2v2`、3012 / 13012 | **分離**。版・人数が違う |
| 位置送信 | host/guest、独立した `sendPosition()`。angle/velocityとゲーム固有データを送る | 4席と connectionId / matchId / round / life / motionRev の検査。 `update()` で必要時だけ送る | **分離**。無理に4席プロトコルを1vs1へ移植しない |
| 位置送信のタイミング | 既存の1vs1送信周期・受信補間を維持 | **移動時80ms・静止時500ms**、向き変更・life/接続世代の変更は再送 | 2vs2の通常・ドラフト **だけ共通化** |
| 弾の表示 | 1vs1専用の短い視覚補間 | actionの受信時に相手の弾を先行表示し、ホスト確定弾へ引継ぎ | **モード特化**。2vs2内部の描画補助だけ共有済み |
| ホスト確定・HP | 2人用の `game` トランザクション／イベント同期 | host actionキュー＋高速ディスパッチ＋host tick＋combatRev制御 | **分離**。2vs2特有の遅延最適化を守る |
| ドラフト能力 | ドラフト進行とカード効果は1vs1用 | GAD2・4人スネーク指名等は2vs2ドラフト固有 | **分離**。発射処理を無条件に上書きしない |
| UI/ボタン配置 | 小画面の独自計算プロファイル | iPad 4人用の独自プロファイル | **保存形式を保って共通ライブラリ化済み** |
| 計測 | 受信間隔、位置・HP遅延 | 同項目に加え、host transaction、action確定、描画遅延 | **指標の意味を共有**、実装・同期方式は独立可 |

## 今回変更した範囲

`shared/runtime/friends-2v2-position-publish.inc.js` は、通常2vs2・ドラフト2vs2の既存コードが**文字列として同一**だった位置送信の判定だけを切り出した。既存の `POSITION_ACTIVE_INTERVAL_MS=80`、`POSITION_IDLE_HEARTBEAT_MS=500`、停止/回転/座標変化の閾値、connectionId・matchId・round・motionRev・life のバイパス条件はすべて据え置いた。

`scripts/build-friends-online.cjs` の4モード生成時に両2vs2へ同じ判定を組み込む。**既存の候補HTMLには実コード変更を加えない。** 1vs1には組み込まない。4つのステージングHTMLはそれぞれGoogle Sitesへ全文貼付け可能な形式を保持する。

CIで次を検証する。

1. 2vs2通常・ドラフトの既存HTMLと共有モジュールの文字列完全一致（生成時の動作変化なし）
2. 初回送信、80ms/500ms、移動開始・停止、姿勢・移動閾値、新接続・新ラウンド・復活
3. 共有モジュールの仮変更が2vs2両方にだけ伝播し、1vs1の通信ソースには影響しない
4. 既存host actionキュー・高速ディスパッチ・決済トランザクションの断片が変わらない
5. 従来のWebKit＋**ローカルFirebase Emulator**による2人・4人テストと、BOT・Google Sites用の回帰テスト

**注意:** 静止時の書き込み数を削減する判定は既存からあるもの。今回は性能がさらに向上したわけではなく、**将来の片方だけの修正漏れを防いだ**。学校Wi-Fiの通信遅延やFirebase本番のRTTは計測していない。

## 次の優先順位

- 2vs2のhost actionキュー・combat tickは共通に見えても**今は触らない**。変更には衝突時の再試行、切断時のホスト移行、ドラフト能力との干渉もテストすること
- 1vs1の位置予測と送信方式は1vs1として改善し、実測なしに2vs2へ寄せない
