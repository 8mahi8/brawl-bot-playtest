# BRAWL タクティカルドラフト｜BOT選択判断 V0.2（試作）
更新：2026-10-18

## 今回変えた点
旧BOTはカードを固定順位で選び、3枚保有時は最初に持ったカードを無条件に交換していた。今回のBOTは**取得後の3枚構成を比較**し、最高の評価値になるカードと交換元を選ぶ。

- **組み合わせ**：空弾疾走＋最後の装填、追撃歩法＋連続圧力等を評価。移動・装填の既存効果上限による重複を減点。
- **相手の所持カードへの対策**：相手が仕留めの一押しを取っていれば崖際装甲・先制防壁を高評価。隠し位置や相手操作を読み取らない。
- **使用キャラ**：タンク・ガンナー・ボマー・スナイパーに応じて防御・装填・追撃の価値を暫定変更。
- **先取り**：勝者先行は維持。相手にも有効なカードを取る妨害価値を少し加える。
- **交換**：全3スロットについて交換後の構成を比較する。4枚目の選択で交換が必要な仕様は変えない。

実装本体は draft/duel-bot-prototype.inc.js の BOT DRAFT POLICY START / END。オンライン公開版は変更しない。スタンドアロンHTMLにも一致するコードをインライン埋め込みしてある。

## テスト
- node tests/draft-bot-policy.cjs ：連携、相手カードへの対策、使用キャラ別判断、交換、2,048件の所持状態で合法な選択のみ行うことを検証。
- node tests/draft-duel-webkit.cjs ：既存WebKit画面操作で勝者先攻・3勝先取・カード交換・通信ゼロを検証。

## 正直な制約
評価点は**手作業のヒューリスティック**。実際の勝率・試合の面白さ・学校iPadの体感は未測定で、BOTの射撃・回避AIは変えていない。プレイ結果を見て係数を後で調整する。
