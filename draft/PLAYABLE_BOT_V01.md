# BRAWL タクティカルドラフト｜1vs1 BOT試作 V0.1

**試作専用・正式公開ではない。** 現行オンライン1vs1から単独BOTモードを継承したHTMLを、通常版とは別の `online/draft-duel-lab.html` に作った。これはGoogle Sitesの正式な公開用 `sites/BRAWL_DRAFT_1vs1.html` ではなく、**開発中のプレイテスト用ページ**。

## プレイ方法

1. [ドラフトBOT試作（GitHub Pages）](https://8mahi8.github.io/brawl-bot-playtest/online/draft-duel-lab.html) を開く。GitHub Pages上に対象ファイルが配信済みの場合だけ有効。
2. 「BOTと練習」→自分とBOTのキャラを選択→「READY」。
3. 第1ラウンドはカード無し。ラウンドに勝った側が4枚の共通カードから**先に選択**する。BOTは自動で選ぶ。プレイヤーはカードをタップ。
4. ラウンド間に取得したカードは次ラウンド以降も保持。1人上限3枚。4枚目のときは画面のドロップダウンで交換元を決める。
5. 先に**3勝**した側が勝利。試合終了後の再戦では所持カードはリセット。

## 最初の8枚：実装している効果

| カード | V0.1実効果 |
|---|---|
| 空弾疾走 | 残弾0の間だけ移動速度+9% |
| 追撃歩法 | 通常攻撃が命中したとき1.8秒間、移動速度+7%（6秒再発動不可） |
| 走行装填 | 0.8秒以上継続移動している間、装填進行+12% |
| 最後の装填 | 残弾0で装填進行+16% |
| 先制防壁 | 6秒以上被弾していないと次の通常射撃ダメージを7軽減（14秒再発動不可） |
| 崖際装甲 | HP35%以下で受ける通常射撃ダメージ8%軽減 |
| 仕留めの一押し | HP35%以下の敵への通常射撃ヒット+5（8秒再発動不可） |
| 連続圧力 | 同一敵に2.5秒以内の通常射撃再命中+3（8秒再発動不可） |

**プレイヤーとBOTの両方に適用**。速度のカード合計強化は12%、装填は20%、同時の追加ダメージは7を上限とする。

## 知っておいてほしい制限

- **1vs1のBOTのみ**。2vs2、オンライン対戦、HOT ZONEのドラフトはまだない。
- 既存のオフライン1vs1実戦を基にしているが、共通の `draft/card-combat-sim.cjs` をそのままインポートしているわけではなく、ゲーム内で動作するカード8枚分を直接統合した段階。発動条件や数値を一元化する前にWebKit試遊テストで固定する。
- 18枚のうち**残り10枚はこの画面には登場しない**。カードの種類を無理に増やす前に、8枚の競合や戦術選択を試している。
- テスト用に追加した `window.__brawlDraftQA` は試作ページ限定。GUIから使う必要はない。
- この試作ではGAD/ULT・ボマー爆弾・毒ガスそのものはカードダメージ補正の対象外。ゲーム固有の威力・効果は基本的に既存の仕様を使用する。複数の弾が1つの攻撃で命中するキャラでは、それぞれの通常弾ごとにカードの発動可否を評価する。
- 連携や視界系の高度なカードは今後の段階。実機での体感遅延とBOT対人の難易度は未測定。
- 公式のGoogle Sites版と正式版 `sites/BRAWL_FRIENDS_*.html` は変更なし。FirebaseのURLは設定不要、対戦中のクラウドへの書き込みは行わない。通常版では通信ボタンが利用可能でも、この試作では明示的に非表示・無効化。
- 通常版とは違う完成度の検証素材なので、先行試用段階では学校の友人向け正式URLとして共有しない。

## テスト方針

`node tests/draft-duel-webkit.cjs` はWebKitでBOT試作HTMLをiframe表示し、1→5ラウンドを実際の画面操作で進行。勝者先攻・BOT自動指名・8枚からの提示・最大3枚入れ替え・3勝先取・Firebaseリクエスト0・例外0を検証する。実際の射撃AI対人バランス、通信経路・iPad実機動作を証明するものではない。通常版の公開ファイルは別の既存テストで固定する。
