# BRAWL Tactical Draft BOT｜V0.4 安定化・品質監査

日付: 2026-10-18

## このターンの対象

**BOT試遊版のみ** (`sites/BRAWL_DRAFT_BOT_PLAYTEST.html`)。通常公開用1vs1・2vs2、オンラインドラフト試作、Firebase本番Rulesには変更なし。カード追加・数値再バランスは今回は凍結し、既存17枚を点検する。

## 確認した整合性バグと修正

- **スモークと草むらで攻撃後の見つかり方が違っていた**：通常射撃・ウルトで発生する既存の`shotReveal`と、追加スモークの独自露出時間の両方を確認する。「潜伏中」「発見中」の表示とBOT視界を同一結果にする。
- **追加の壁が弾を止めてもBOTの射線判断で無視されていた**：既存マップ壁と4秒のポータブルウォールを`lineBlocked`の障害物判定へ統合。もともとの通常マップは不変。
- **分身のAIが相手の草むら/煙幕による潜伏を無視して見せ弾を撃つ場合があった**：分身が敵を見つけていないときは撃たないようにし、ダメージ0の視覚用弾と本物の弾を完全に分離。
- **カード説明が古かった**：反動22→60、縦長壁42×112、壁越しワープ、分身のゼロダメージ、煙幕の隠密説明を実際の挙動と一致させる。

## UI・表示

- GAD2ボタンのカード名とCD表示は前バージョンから継続。無駄なDOM属性書換えを減らす。
- 使っている能力の残り時間を表示する小さなステータスHUD追加（分身・壁・地雷・帰還・煙幕潜伏/発見）。プレイ中だけ表示し、操作の邪魔にならない。
- GAD2配置・サイズ、元GAD/ULTの位置調整は継続。小さい横画面ではカード選択・配置UIの余白と最低文字サイズを見直し。
- ボタン・カードのフォーカス状態を見やすくし、装備中カードの表示を更新。

## 回帰試験

`tests/draft-bot-playstyle-webkit.cjs` に既存のローカルWebKitのタッチ/クリック検証に加えて以下を追加:
- 追加壁による射線ブロック
- 煙幕が攻撃/ULTによる発見状態と一致すること
- GAD2選択変更時の読み上げ用ラベルの更新
- タンク/ガンナー/スナイパー/ボマー全4キャラで複合カードを装備して実際に射撃すること
- 1024x400横画面でカード選択とボタン編集の操作入口が残ること

以前からの分身のゼロダメージ・実見せ弾、縦長壁、7秒持続、壁越しワープ、レイアウト保存、3勝先取等のテストも維持。

## 未検証・公開上の制約

GitHub Actions WebKitは学校iPad実機ではない。またBOTの思考が全局面で最適か、カード強弱が絶対に均等かを保証するものではない。実際の友人とのドラフトオンライン公開は別工程であり、本レポートを根拠に公開設定を変更しない。
