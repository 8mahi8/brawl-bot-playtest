# BRAWL｜新カード BOT 試遊版

**プレイ用HTML**：`sites/BRAWL_DRAFT_BOT_PLAYTEST.html`（HTML単体・Firebase接続ゼロ）。
既存の `online/draft-duel-lab.html` を直接ベースにして**通常版1vs1・2vs2やオンラインドラフト版へは変更を加えない**。
同じGitHubリポジトリ内であっても新しい実験用HTMLとして別管理する。

## まずBOTと遊ぶ

1. 新しいプレイ用HTMLを開く。GitHub Pages がこのリポジトリ全体を main から提供している場合は `https://8mahi8.github.io/brawl-bot-playtest/sites/BRAWL_DRAFT_BOT_PLAYTEST.html`。リンクが表示できない場合は本ファイル全文をGoogle Sitesの「埋め込む→コードを埋め込む」に貼り付けて使う。
2. 「BOTと練習」→ 自分のキャラ・BOTキャラ/難易度を選ぶ。
3. 「**新カードを選んで試す（任意）**」で9枚から最大3枚選ぶ。省略時はドラフトのランダム提示から取得する。
4. READYでプレイ。PCはWASD/左クリック射撃、右クリックGAD、Space/Eウルト、**FでGAD2**。タッチでは従来の射撃/移動と既存GAD/ULTに加え、紫色のGAD2ボタンを利用。
5. 画面の「縦幅 ⚙」→「ボタンの位置・サイズを調整」から、GAD・ULT・GAD2を**ドラッグ移動しながら同じ画面のスライダーでサイズ調整**。位置・サイズは保存される（BOT試遊版用に独立保存）。
6. 3勝先取。ラウンド勝者が先に新旧17枚の中から選択。勝者先攻のルールを保つ。

## 今回の効果（初期検証値）

| 新カード | BOT試遊版での挙動 |
| --- | --- |
| 分裂弾 | タンク5発/ガンナー3発の**中心弾だけ**射程半分で左右2弾に分裂、各60%。スナイパー単発も分裂。ボマーは通常投げを各半分の小爆発2個へ置換 |
| 跳弾 | 通常弾が壁に当たると1回反射、以後の威力70%。弾が無限に増えない |
| 反動射撃 | 通常射撃+10%のダメージ計算と、1射撃につき60座標分後退（1.2秒の反動クールダウン）。壁との衝突を維持 |
| 遅延爆発 | 一度でも通常弾が命中したら0.7秒後に10ダメージの小爆発、同じ射撃バーストで最大1個。3秒発動間隔 |
| ポータブルウォール | GAD2：4秒の小さな壁。自分や敵の位置に直接重ならない |
| トラップマイン | GAD2：最大9秒存続。敵が踏むと8ダメージ+1.4秒鈍足 |
| ホログラム | GAD2：最大7秒の分身。BOTは囮にも狙いを向ける。通常弾に当たれば消える |
| ワープビーコン | GAD2：置いて7秒以内に再押しすると帰還。最大260距離、移動経路の壁を貫通しない |
| スモーク | GAD2：4秒の煙幕、遮蔽の外からは見つけにくい。攻撃すると700ms位置を晒す |

## 重要な制限

- **BOTとの1vs1試遊版だけ**。新9枚をオンライン版のプールへはまだ投入していない。
- 初期実装は効果の感触を確認する目的。特にボマーの既存強化爆弾と分裂/反動の同時処理、複数射撃効果の重ね掛け、HOLOGRAMとスモークの情報秘匿は追加レビュー対象。
- **GAD2は1個だけ**。同カテゴリを複数所持する場合は**新しく取得したガジェットをGAD2に上書き装備**する（所持カードは残る）。ラウンドの始めに装備が確定する。
- 分身には見た目・挙動の磨き込み余地があり、ワープは経路が遮られている場合は使用不可にしている。壁を無視して瞬間移動できるわけではない。
- 18歳未満の利用が想定される学校iPadはタッチ操作・音声なし。横画面の表示と通信は実機で確認する。
- **通常版とオンライン版の公開ファイルは変更しない**。これはローカル無通信の試用成果物であって、友達とオンライン対戦するための新モード正式リリースではない。
