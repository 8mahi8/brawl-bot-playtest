# BRAWL Tactical Draft｜開発の現在地

更新：2026-10-18

## 原則
- **通常版とドラフト版の差はドラフト機能だけ**にする。ロビー・対戦UI・操作・マップ・既存戦闘はそれぞれの通常開発版を基準にする。
- 1vs1と2vs2は既存の別エンジンを維持し、2vs2を一から作り直さない。
- 友達との実戦を優先。カード間の細かな強さ調整は公開後の遊びで考える。
- どちらかの開発版へ入った操作/UI/安定性改善は、ドラフト版へも必要に応じて取り込み、差分をレビューする。**自動同期は未実装**。
- **両方遊べる状態で同時公開**する。Google Sitesには各HTMLのコード全文を直接埋め込む。既存通常版を勝手に更新しない。

## 最新カード採用方針（2026-10-18）

ユーザーレビューにより、**戦い方が変わる新カード9枚を試作採用**。旧候補05「追跡マーカー」は不採用。特に旧03「反動射撃」は反動移動に加えて通常攻撃の威力+10%を仮採用し、旧04「遅延爆発」はタンク5弾・ガンナー3弾でも**射撃アクション1回につき爆発最大1個**とする設計。カード候補と調整値は `draft/STYLE_CHANGING_CARDS_V1.md` / `draft/style-changing-cards.v1.json` で管理する。

**9枚は設計承認のみで、まだ戦闘へ実装していない。** 実効果と同期検証が終わるまで正式ドラフト候補へ追加しない。GAD2を使う5枚は通常GADを残したまま、ドラフトモードだけに追加のGAD2ボタンを1枠用意する方向。

## まだ公開できない理由
両ドラフト開発HTMLは**localhost限定**で、ローカルFirebase RTDBエミュレーターにのみ接続する。既存の本番Firebase Rules/Auth/Google Sitesは変更していない。これは本番ルームの権限・通信・実機表示の確認をせずに公開して事故を起こすのを避けるためである。

## 次の実装順
1. 実際の戦闘からKO→カード指名→再戦へのSafari/WebKit E2Eと切断復帰試験を通す。
2. 1vs1/2vs2のUI、操作、表示がそれぞれの最新通常開発版と一致するかチェック（ドラフト独自部分は除く）。
3. クラウド側の本番とは隔離したアクセス方式、Firebase Auth/Rulesを整える。既存通常ゲームを壊さない。
4. 学校iPad横向きSafari/Google Sites埋め込みで、両方の実機通信を確認する。
5. 両方の`sites/BRAWL_DRAFT_1vs1.html`と`sites/BRAWL_DRAFT_2vs2.html`を独立した完成品として出し、本人がGoogle Sitesへコードを貼り付けて公開。

ローカル試験用HTMLだけではGitHub PagesやGoogle Sitesから通信できない。**試作品のmainマージは公開完了を意味しない**。
