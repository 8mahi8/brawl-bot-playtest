# 夜霧の脱出 v0.2（スマホ操作改善版）

「第五人格」の追跡・解読・脱出要素に着想を得た、非公式オリジナルのブラウザゲーム。BOT相手の一人用です。

## 遊び方

- iPhone / iPad: GitHub Pages のURLを Safari で開く。左下エリアをタッチして移動、右の「調べる」を長押し、ダッシュボタンで加速。
- PC: WASD/矢印キーで移動、E/スペースで解読、Shiftでダッシュ。
- 暗号機を3台解読し、南東のゲートを開けば勝ち。

このディレクトリはBRAWL本体から独立しています。BRAWLのルート `index.html` は変更していません。

GitHub Pages が `main` / `/(root)` を配信する場合の想定URL: https://8mahi8.github.io/brawl-bot-playtest/yorugiri/

実機Safariの操作性とPages公開状態の確認は未完了です。
